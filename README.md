# Quota Halo for Windows

An evolved Windows take on the [Codenotch](https://github.com/vinzdg/codenotch) idea: a
small black **halo** pinned to a screen edge that shows the live
usage / credit readings of the AI coding accounts on this machine, side by
side. Hover the pill and it unfolds into a card of provider rings; move the
mouse away and it folds back. It lives in the system tray.

## What it reads

| Provider | Reading | Credential source (borrowed, never written by this app) |
|---|---|---|
| **DeepSeek** | remaining USD (the DSH harness backend) | `DEEPSEEK_API_KEY` in `~/.dsh/.credentials.yaml` |
| **OpenRouter** | remaining prepaid credit | Management API key in Settings, or `OPENROUTER_API_KEY` env/file |
| **Claude** | usage windows (session / all models) | Claude Code OAuth, with Claude Desktop's official local usage cache as fallback |
| **Codex** | 5h + weekly usage windows | `tokens` in `~/.codex/auth.json` |
| **Antigravity** | Gemini quota, else a local "requests today" count | Windows Credential Manager `gemini:antigravity` (Go keyring) |

Ring colors follow the original palette: 🟢 ample, 🟡 watch (< $5 / ≥80% used),
🟠 critical / token expired / sign-in needed.

Transient fetch failures keep the **last good reading** visible and mark it
*stale*. Claude prefers the live OAuth endpoint; if the Claude Code login has
expired but Claude Desktop is active, Quota Halo uses its fresh local usage
cache without reading or copying the Desktop session token.

## Requirements

- Windows 10/11 x64. DSH for the DeepSeek reading; the CLI/desktop apps for
  the providers you want to see (each ring degrades to *sign in* honestly when
  its credential is absent).

## Build & package (recommended, single flow)

```sh
npm install          # first time
npm start            # dev run

npm run package      # → dist/Quota Halo-win32-x64/Quota Halo.exe
npm run smoke        # verifies the packaged bundle has main/renderer/settings/preload/assets
                     # (SMOKE_LAUNCH=1 npm run smoke also boots the exe for 6s)
```

`npm run package` runs `scripts/package.js`, which reads the version from
`package.json` (never hard-coded) and embeds `assets/icon.ico` as the exe
icon. Icons are generated by `scripts/make-icons.js` (PNG) and
`scripts/make-ico.ps1` (ICO); re-run them after editing the icon drawing.

## Settings (tray icon, or ⚙ on the expanded card)

- Enable/disable each provider (order is fixed left→right).
- **OpenRouter Management API key** — paste an `sk-or-…` Management API key to
  read the account's purchased-credit balance, or set it as
  `OPENROUTER_API_KEY`. A normal inference key can show only its own configured
  spend cap; it cannot read the account-wide balance.
- DeepSeek credentials file + key name.
- Screen edge (top/bottom), poll interval (the notch polls more often while
  DSH is actively writing), pin open, launch at sign-in.
- **Credential probe** shows what each provider found.

## Notes

- The notch window uses `win.setShape`, so only the pill/card is clickable and
  the transparent surround never blocks the desktop.
- Antigravity endpoints are Google's own (`cloudcode-pa.googleapis.com`).
  Personal accounts get 403 on the quota endpoint (Google won't publish a
  limit), so the ring honestly shows a local *count of model requests today*
  from `~/.gemini/antigravity/brain/*/.system_generated/logs/transcript.jsonl`.
- Antigravity's credential is read from Windows Credential Manager via a tiny
  `CredRead` P/Invoke through `powershell -EncodedCommand` (`src/providers/wincred.js`).
- Debug self-check: `CODENOTCH_DEBUG=1 npm start` writes a DOM/render report to
  `debug/report.json` after the first poll, then quits.

## Known limitations

- **Private endpoints.** Claude (`api.anthropic.com/api/oauth/usage`), Codex
  (`chatgpt.com/backend-api/wham/usage`) and Antigravity
  (`cloudcode-pa.googleapis.com`) are not published APIs. They can change or
  be removed; the notch degrades honestly (stale / needsAuth) rather than
  guessing. Parser contract tests live in `tests/`.
- **Credentials.** DSH (`~/.dsh/.credentials.yaml`), Claude Code
  (`~/.claude/.credentials.json`) or Claude Desktop's local usage cache, Codex (`~/.codex/auth.json`) and
  Antigravity (Windows Credential Manager `gemini:antigravity`) must already be
  signed in. Claude refreshes only with the CLI file's existing refresh token;
  its Desktop fallback reads usage percentages only and never extracts the
  encrypted Desktop session.
- **Offline / cold start.** On launch the notch immediately shows the last
  persisted good reading (`%APPDATA%\Quota Halo\last-state.json`),
  then re-polls. If a poll fails the ring keeps the last numbers and marks them
  stale instead of blanking.
- **Antigravity license.** Personal Google accounts get HTTP 403 from the quota
  endpoint (Google publishes no limit), so the ring falls back to a local count
  of today's model requests from Antigravity's transcripts. A licensed account
  shows real weekly / 5h percentages.
- **Always-on-top.** The notch uses `screen-saver` level by default and can be
  switched to `normal` in Settings so it does not cover fullscreen apps or
  games. It does not auto-hide during fullscreen yet.
- **Single-language provider rows.** The notch chrome and Settings window are
  i18n'd (zh-TW / en) via `renderer/i18n.js`, but some provider-supplied strings
  (e.g. "Available now", window labels) are still English.
- **Settings & uninstall.** Preferences live in
  `%APPDATA%\Quota Halo\settings.json` and last readings in `last-state.json`.
  On first launch, settings are copied from a legacy Codenotch folder when
  needed. Uninstalling the portable build leaves these files behind; delete the
  `Quota Halo` folder to remove them. A pasted OpenRouter key is protected with
  Windows DPAPI when available.
- **Multiple monitors.** The notch remembers the screen and position you drag it
  to and re-homes if that display is removed; it does not yet follow a display's
  DPI change across a live session without a reposition.
